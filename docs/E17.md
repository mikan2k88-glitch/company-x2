# E17 — 顧客向け日英表示と公開紹介

公開 `/services` で4サービス、検証料金、入力上限、データ送信・保存条件、受付手順を紹介。`?lang=ja` または `?lang=en` と画面のLanguage選択で表示を切り替えます。管理画面は日本語です。

`/intake` は日英対応。言語は同じタブのsessionStorageへ保存し、Stripeから戻っても復元。切替は表示だけを変更し、CSV本文・ハッシュ・注文・同意・計画を変更しません。原文ノードを保持し、動的な進行表示も辞書で翻訳します。外部翻訳APIは使いません。ブラウザーの日本語以外の言語は英語で案内します。

会社画面の顧客向け言語を選んで受付リンクと応募文を作成できます。新規StripeテストCheckoutにja/enを指定。既存セッションは元の言語のまま。JPY100、冪等キー、所有者チェックは維持。本番決済・自動応募は未稼働です。

公開紹介ページは招待トークンを発行しません。APIは管理認証または既存の期限付き招待が必要です。一般閲覧者の受付と有償受注はまだ開始していません。追加SQL・環境変数は不要。

検証: JSで日英往復、動的状態、CSV文字列保持、ハッシュ保持。HTTPで公開ページ・未認証API拒否・言語付き招待・決済localeと金額・英語の未送信応募文。既存の受付から受領までのテストも継続。

Stripe locale参考: https://docs.stripe.com/api/checkout/sessions/create
