# E16 — 探索精度と応募準備

毎時クラウド探索を8検索のローテーションへ拡張。bountyに加え直接依頼・paid・requestを探索し、範囲候補を保存時に優先します。1時間1検索、最大10結果・4候補と既存1件の再確認。対象は公開GitHub Issueのみ。

会社画面に原文リンクと依頼・報酬・期限・支払・AI条件の最大300文字の記載を表示。引用は未検証で、支払者の合意や資金を保証しません。期限欄のISO日付がUTC当日より前なら除外。曖昧な期限は確認待ちです。重複・更新90日超・範囲外の判定は維持。

応募文と条件付き見積もりは対応サービス・処理範囲・UTF-8 CSV 1MB/10,000行・無料検証0円・Stripeテスト100円を表示。本番料金・納期は未確定。送信・自動応募・実決済は行いません。AI条件の記載は応募許可の確定ではありません。

更新ボタンは営業情報も更新。除外内訳を表示。追加SQL・キー・有料サービス不要。有償案件獲得はまだ未達成です。

検証: 期限前後、曖昧期限、引用、重複、権限未付与、条件付き見積もり、既存受付・決済・納品テストとPostgreSQL CI。
