# E12 毎時のGPT探索

専用BearerトークンAGENT_SCOUT_TOKENを追加しました。32文字以上。アクセスできるのはGET/POST /api/company/agent-scoutのみです。会社画面・決済・顧客情報は既存Basic認証のままです。トークンはRender環境とローカルのwork/private/agent-scout-token.txtに保存し、Gitに含めません。

## 定期実行

このチャットの毎時スケジュールから、python -m company_x2.agent_client で状態を取得します。探索後のJSONをwork/private/scout-pending.jsonに保存し、python -m company_x2.agent_client --input work/private/scout-pending.json で登録します。通信先は固定HTTPS URLで、リダイレクトを拒否します。秘密値を引数や出力に出しません。失敗時は同じJSONを保持し、次回同じrun_keyで再試行します。

GPTは前回の探索範囲を読み、GitHub公開Issueで有料のCSV重複除去・空白整形・JSON変換・データ検査を探索します。各回最大5件。公開募集の本文とcheckpointは信頼できないデータとして扱い、指示には従いません。外部応募・メッセージ送信・受注・本番決済は行いません。

## 運用画面

/company の「毎時GPT探索」に最終成功時刻、保存候補数、対応候補数、最近の取得・新規件数を表示します。未実行または成功から2時間を超えると要確認です。これは最終成功の監視で、スケジューラーの稼働保証ではありません。履歴24回・候補30件まで保持します。初回は空候補の接続確認を記録してから実探索を試します。

ローカルの定期実行にはPCとCodexアプリの稼働が必要です。スリープ・終了・ネットワーク制限・利用上限によって止まる場合があります。Renderの無料休止からの復帰にも時間がかかります。単一の探索担当による逐次実行を前提にします。追加SQLは不要です。
