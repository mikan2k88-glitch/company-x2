# E13 PC不要のクラウド探索

Render Cronから毎時 python -m company_x2.agent_client --cloud-run を実行します。探索専用トークンだけをCron環境へ設定し、既存WebサービスのAPIで募集取得・判定・保存を行います。SupabaseとAI・決済の秘密キーをCronへコピーしません。追加SQLは不要です。

CSV重複除去・空白整形・JSON変換・データ検査のGitHub公開Issue検索を順番に巡回します。各回検索最大10件から最大4候補を選び、既存候補最大1件を再確認。Issueを再取得して条件を判定します。同じUTC時間の再実行は保存履歴で重複を防ぎ、失敗時は次の探索範囲へ進みません。候補30件・履歴24回まで。

これはPC上のGPT定期呼び出しをクラウドの定型探索に置き換える構成です。毎回GPTやGeminiを呼び出す機能ではなく、AI利用費は追加しません。複雑な営業判断・応募・受注・本番決済は実行しません。Web側の既存Gemini判断機能は利用できます。

Render Cronは1サービスにつき月額最低1米ドル、実行時間による従量課金です。毎時17分に実行します（UTCで設定、どの時差でも毎時）。PCとCodexアプリは不要です。RenderがCronの同時実行を防ぎます。Web無料サービスの休止からの復帰には待ち時間があります。クラウド接続の障害やGitHubの取得制限はCronの失敗として記録し、次回再試行します。

会社画面の最終成功・取得件数・新規件数を確認できます。障害はRenderのRuns/Logsを確認してください。以前のPC依存Codexスケジュールは停止します。クラウドからCodexチャットへ通知する機能はありません。
