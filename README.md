# Company X2
仕事探しから受注・制作・検品・納品・入金まで、人の介入なしで完結するAIカンパニーを目指す新規プロジェクト。

現在はRenderとSupabaseで動く、パスワード付きWeb試作です。依頼受付・CSV加工・検品・成果物ダウンロードを実装しました。
E03でGitHub公開APIからの募集候補探索・保存・選別・画面表示を追加しました。[追加SQLと適用手順](docs/E03.md)。
E04でCSV空白整形・JSON変換・データ検査と、サービス選択・形式別納品を追加しました。[E04の追加SQLと処理条件](docs/E04.md)。
E05で定型依頼文の判定・事前検査・作業計画・計画からの自動処理を追加しました。[E05の使い方と範囲](docs/E05.md)。
E06〜E09で候補の確認順位、任意のOpenAI判断、合意記録と納品、Stripeテスト決済の照合を追加しました。[設定と検証範囲](docs/E09.md)。会社運用画面は `/company` です。新しい受注DBには009_company.sqlの適用が必要です。
E10で探索候補の整理・見積もり下書きと、専用のCSV依頼受付 `/intake` を追加しました。[E10の使い方](docs/E10.md)。追加SQLは不要です。
AIとStripeはキー・予算が未設定の間は停止します。実際の応募送信・外部受注・本番決済は未稼働で、実売上はありません。
E11で定期GPT向けの公開Issue登録・再開メモAPIを追加しました。[E11の接続手順](docs/E11.md)。スケジュール登録は別途必要です。
E12で探索専用認証、固定接続クライアント、毎時探索の運用状態表示を追加しました。[E12の運用](docs/E12.md)。
E13でRender CronによるPC不要の毎時探索を追加しました。[E13の運用と費用](docs/E13.md)。
[企画と実装計画](docs/PLAN.md)に目標、営業経路の課題、既存資産の使い方を記載しています。

## 検証
Python 3.12以上、追加ライブラリなし。
```sh
python -m unittest discover -s tests -v
python -m company_x2.server --port 8080
```

## 初期実装
- 顧客向けWeb画面、受付・進捗確認・ダウンロード
- SQLiteの案件保存、顧客トークン、重複受付防止、中断案件の再開
- 案件状態遷移と証拠・採算のチェック（実取引用の純粋なルール）
- CSV完全一致重複除去と出力検品
- 公開Issue候補の毎時探索・保存・適合判定、構造化候補の手動取り込み
- Supabase用の隔離スキーマと注文・探索RPC
- GitHub Actionsのテスト

この状態遷移は外部証拠の真正性を検証しません。実運用には永続化・外部コネクター・決済照合が必要です。

[起動方法・運用範囲](docs/RUNBOOK.md)。ローカル画面は http://127.0.0.1:8080 です。
Renderではパスワード付き限定試作として起動できます。[RenderとSupabaseの設定手順](docs/RENDER.md)。
一般公開の有料サービス用HTTPサーバーではありません。実取引ルールとsandbox注文は分離し、無料加工を売上として計上しません。

E14でクラウド探索の障害診断・待機と、失敗記録を除いた成功表示を追加しました。[E14の運用](docs/E14.md)。無料RenderとChatGPTクラウドタスクを利用し、追加SQLは不要です。
